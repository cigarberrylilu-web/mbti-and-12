# 设计:BGM/电影/诗 板块内容改造

日期:2026-06-09
项目:mbti-and-12(星格解析档案 · MBTI×12星座深度报告)
文件:`src/data/reportData.tsx` 中每条记录的 `media: { bgm, movie, poem }`

## 1. 背景与问题

192 组(16 MBTI × 12 星座)各有 bgm/movie/poem 三项,共 576 条。审计结果:

- **电影**:135 个不重复,88 条用的是重复片(46%)。《星际穿越》6×、《荒野生存》《楚门的世界》《黑客帝国》《教父》各 5×。
- **BGM**:143 个不重复,76 条重复(40%)。Lana Del Rey《Young and Beautiful》6×,Oasis/Radiohead/Hans Zimmer 各 5×。
- **诗**:191 个基本不重复,但都是 AI 原创的西式翻译腔短句。
- 整体几乎清一色欧美作品,与"人格×星座"契合度低。

## 2. 已确认的决策

1. 文化分配 **以 MBTI 人格为主轴**,星座做微调。
2. 非西式素材库 = **泛东亚**(华语 + 日/韩影音)。
3. **不设固定中西配比**,由每型风格基调自然决定。
4. 诗 = **按人格混搭真实诗句**(古典气质→中国古诗词;疏离/现代感→中外现代诗)。诗字段格式:`「短句」—— 作者《篇名》`,句子要短、能放进小卡片。
5. 去重:**同一作品全站最多出现 2 次,且两次人格都要真契合**。

## 4. 星座微调(在人格基调上叠加情绪色,不换文化)

- 火象(白羊/狮子/射手):加热烈、外放、行动力
- 土象(金牛/处女/摩羯):加沉稳、质感、长期主义
- 风象(双子/天秤/水瓶):加灵动、思辨、疏离美
- 水象(巨蟹/天蝎/双鱼):加细腻、深情、宿命感

## 5. 选材与去重规则

- **退役烂大街清单**(优先不再用或最多 1 次):《星际穿越》《楚门的世界》《黑客帝国》《教父》《荒野生存》、Lana Del Rey《Young and Beautiful》、Oasis、Radiohead《Creep》、Hans Zimmer《Time》。
- 选**真实存在**的作品;用"高辨识但没被用烂"的,不用生僻到没人知道的。
- 同一作品全站 ≤2 次,且两次都真契合。
- "≤2 次"约束针对**作品**,不针对作者/导演;同一作者不同作品可多次。

## 6. 执行计划

1. 先做 **INFP 样板型**(12 星座 × 3 项),在对话里展示给用户确认风格/审美/契合度。
2. 样板通过后,**按 MBTI 逐型推进**,每型 12 组,改完一型用户扫一眼放行。
3. 直接改 `reportData.tsx` 的 `media` 字段;每型一次 commit;全部完成后再统一决定是否推送上线(`git push` → Cloudflare Pages 自动部署)。
4. 每型完成后用 `_audit_media.py` 复跑,确认无作品 >2 次。

## 7. 验证

- 每型改完跑 `_audit_media.py` 查重复;全部完成后 `npm run build` 通过;不改动 media 以外的任何字段/结构。
